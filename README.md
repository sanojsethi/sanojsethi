# TCS FY2026 Business Performance Analysis

## Project Overview

This project analyzes TCS FY2026 business performance using Power BI, PostgreSQL, SQL validation, and business intelligence techniques.

The project focuses on revenue, profitability, revenue growth, industry performance, regional revenue mix, and FY2025 vs FY2026 comparison.

## Tools Used

- Power BI
- PostgreSQL
- SQL
- Microsoft Excel
- Power BI DAX

## Key KPIs

- Total Revenue: ₹267.02K
- EBIT: ₹66.838K
- PAT: ₹52.82K
- Net Margin: 19.78%
- Revenue Growth: 93.84%

## Dashboard Analysis

The Power BI dashboard provides analysis of:

- FY2026 Revenue by Industry
- FY2026 Net Margin by Industry
- Revenue Mix by Region
- FY2025 vs FY2026 Revenue by Industry
- Key Financial KPIs
- Industry filtering

## Business Insights

The project contains 15 business findings and recommendations covering revenue growth, profitability, industry performance, regional concentration, and strategic opportunities.

## Project Workflow

Excel Data
→ PostgreSQL
→ SQL Validation
→ Power BI
→ Dashboard
→ Business Insights
→ Recommendations

## Outcome

This project demonstrates practical data analyst skills including data validation, SQL analysis, data visualization, KPI development, business interpretation, and dashboard storytelling.
